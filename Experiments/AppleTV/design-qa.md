Evidence: `build/validation/tvos-bridge-ui-20261105/comparison-v1.png`（仓库根目录下）。实现取自 UI 测试确认主按钮已获得焦点的截图；启动动画尚未完成的早期截图不用于焦点判断。

- P2 / 图标：house 的实心门与桥接箭头重叠，含义不清。改用原生 SF Symbols 的 HomeKit 图标，保留绿色状态徽记。
- P2 / 排版：首页标题和主按钮字号小于目标，弱化首要操作。增大主标题与按钮文字，调整图标至标题、标题至说明的距离。
- P2 / 布局：GeometryReader 从默认安全区取得较小宽度，侧栏约 334 点而非设计的约 360 点；修正全屏测量，继续由内部内容边距保留安全空间。收紧右栏行距以匹配目标。

初始焦点、桥接启停、设备详情的示例状态切换已通过遥控器测试。真实前台运行时测试因测试脚本预设向右就落到首行而中断；按实际方向导航补齐向上选择后复测。

第二轮发现 P1 / 稀疏设备状态焦点：只有一台设备时，右栏 focusSection 高度随内容收缩，从下方主按钮向右无法进入设备区。右栏 focusSection 改为填满可用高度，保持单台设备也能以遥控器到达；增加完整设备筛选与设置表单测试。
