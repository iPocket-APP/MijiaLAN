# MijiaLAN 0.1.5

原生 macOS 版，Build 6。支持 macOS 15 及以上，安装包同时包含 Apple Silicon 和 Intel。

- 修复 HomeKit 批量读取的响应格式：当部分设备读取失败时，`207 Multi-Status` 响应中的正常读数也会明确返回 `status: 0`，避免遗漏成功状态导致正常设备的状态读取受到影响。
- 保留失败设备自己的错误码；全部读取成功时仍返回 `200 OK`，不额外添加状态字段。
- 新增经过 Pair Verify 认证的混合读取回归测试，检查正常设备的值、离线设备的错误，以及全部读取成功的响应格式。

安装包由 GitHub Actions 测试、构建、签名和公证，通过 macOS 15 双架构启动检查后发布。可用 `SHA256SUMS.txt` 核对下载文件。不同设备、固件和家庭中枢仍需结合实际使用确认。

---

Native macOS release, build 6. Requires macOS 15 or later; Universal for Apple Silicon and Intel.

- Fix partially failed HomeKit batch reads: successful entries in a `207 Multi-Status` response now explicitly include `status: 0`, so missing success statuses do not interfere with reading reachable accessories.
- Preserve each failed characteristic's error code. Fully successful reads continue to return `200 OK` without extra status fields.
- Add a regression test using real Pair Verify authentication for mixed successful/failed reads and the fully successful response format.

GitHub Actions tests, builds, signs and notarizes the packages, then checks startup on both CPU architectures running macOS 15 before publication. Verify downloads with `SHA256SUMS.txt`. Device, firmware and home-hub behavior still requires validation in actual use.
