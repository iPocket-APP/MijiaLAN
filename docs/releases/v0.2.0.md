# MijiaLAN 0.2.0

## 简体中文

原生 macOS 版，Build 26。支持 macOS 15 及以上，同一安装包适用于 Apple 芯片和 Intel。

- 在「设置 → 管理家庭设备」中展开设备，可分别选择要加入 Apple「家庭」的开关和传感器。关闭某一项前，请留意使用它的场景和自动化。
- 米家智能插座 3 优先显示电源和设备温度，童锁、倒计时和功率限制等收在「高级项目」中。
- 「家庭」中名为「开关 14」之类的项目，在管理页会显示实际功能名，原有名称放在副标题中，方便对照。

可在设置中检查更新，或从 GitHub Releases 下载经 Developer ID 签名和 Apple 公证的安装包。

## English

Native macOS release, build 26. Requires macOS 15 or later. The Universal installer supports Apple silicon and Intel.

- Expand a device in Settings → Manage Home Devices to choose which switches and sensors appear in Apple Home. Check any scenes and automations that use an item before turning it off.
- The Xiaomi Smart Plug 3 shows power and device temperature first, with child lock, countdown and power limits under Advanced Controls.
- If Home assigned a label like “Switch 14,” the settings list shows the function as the title and the saved Home name underneath.

Check for updates in Settings or download the Developer ID signed and Apple notarized installer from GitHub Releases.
