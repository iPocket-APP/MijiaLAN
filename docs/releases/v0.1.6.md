# MijiaLAN 0.1.6

## 简体中文

- 新增内置软件更新：可在设置或菜单栏右键菜单中检查更新，查看说明并安装。
- 默认每天自动检查，自动下载与退出时安装默认关闭，可在设置中选择开启。
- 常驻时通过菜单栏图标和面板提示可用更新，后台提示不会抢占其他 App 的焦点。
- 更新清单通过 `mijialan-updates.ipocket.xyz` 提供，安装包托管于 GitHub Releases；安装前验证更新包签名。
- 更新重启时家庭桥接会短暂离线，设备凭据和 HomeKit 配对资料继续保存在原钥匙串项目。

未内置更新器的旧版需要从 GitHub Releases 手动安装一次。此后的版本可以使用内置更新。

## English

- Add in-app updates from Settings or the menu-bar context menu, including release notes and installation.
- Check daily by default. Automatic downloads and installation on quit are optional and off by default.
- Show available updates in the menu bar and panel without letting background reminders steal focus.
- Serve the update feed from `mijialan-updates.ipocket.xyz` and packages from GitHub Releases, verifying the archive signature before installation.
- Updating briefly interrupts the Home bridge while the app restarts. Device credentials and HomeKit pairing material remain in the existing Keychain item.

Older versions without the updater require one manual installation from GitHub Releases before in-app updates are available.
