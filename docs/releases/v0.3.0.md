# MijiaLAN 0.3.0

## 简体中文

原生 macOS 版，Build 40。支持 macOS 12 及以上，同一安装包适用于 Apple 芯片和 Intel。

- 扫码导入后可选择「记住米家登录」。登录保存在本机钥匙串，下次可直接点「重新导入」。会话过期时重新扫码，也可随时在设置中忘记登录。
- 养生壶在 Apple「家庭」中提供煮茶、果茶、银耳、炖汤、烧水和保温六个独立开关。打开即可启动对应菜单，关闭正在运行的菜单开关即可停止。开关会同步壶的实际运行菜单。这版也修复了部分厨房设备的启动参数。
- 修复从浅色或深色切回「自动」时，菜单栏面板未立即恢复系统外观的问题。
- 改善家庭中枢重连后的状态同步。诊断报告增加设备命令结果、局域网读取统计和桥接服务状态。

已有的「家庭」配对可直接用于升级。引用旧养生壶控件的场景和自动化可改选对应的菜单开关。

可在设置中检查更新，或从 GitHub Releases 下载经 Developer ID 签名和 Apple 公证的 DMG 或 ZIP。

## English

Native macOS release, build 40. The Universal installer supports macOS 12 and later on Apple silicon and Intel.

- Choose Remember Xiaomi Home Login after a QR import. The app saves the session in the local Keychain so you can use Re-import Devices next time. Scan again if the session expires, or forget the login in Settings at any time.
- The health kettle has six individual switches in Apple Home for tea, fruit tea, tremella, soup, boil water, and keep warm. Turn a switch on to start its menu, then turn it off to stop the run. The switches show which menu is running. This release also fixes start arguments for some cooking devices.
- The menu bar panel now follows the system appearance when you switch back to Auto from Light or Dark.
- Improves state sync when a home hub reconnects. Diagnostic reports now include device command outcomes, LAN read statistics, and the state of bridged services.

Existing Apple Home pairings carry over. Update any scenes or automations that used the old kettle controls to select the corresponding menu switches.

Check for updates in Settings, or download the Developer ID signed and Apple notarized DMG or ZIP from GitHub Releases.
