# MijiaLAN 0.4.0

## 简体中文

原生 macOS 版，Build 46。通用安装包支持 macOS 12 及以上，适用于 Apple 芯片和 Intel。

- 新增「引导教程」，分步导入米家设备、选择要桥接的设备，并将桥添加到 Apple「家庭」。可随时从设置重新打开教程。
- 「管理家庭设备」新增配对诊断。可标记一次配对尝试，记录 iPhone「家庭」显示的结果，再导出包含 Bonjour 发现和 HomeKit 配对进度的诊断报告。
- 改善未配对时刷新设置码的流程。桥接启动失败后，可在「管理家庭设备」中重试启动。
- 改善局域网读取。一批属性中有部分读取失败时，保留成功读取的值。导出诊断时可同时检查离线设备的连通情况。

直接升级会沿用已有的 Apple「家庭」配对。手动重置配对会生成新的桥身份，需要在「家庭」中重新添加桥。

可在设置中检查更新，或从 GitHub Releases 下载经 Developer ID 签名和 Apple 公证的 DMG 或 ZIP。

## English

Native macOS release, build 46. The Universal installer supports macOS 12 and later on Apple silicon and Intel.

- The new Setup Guide walks you through importing Xiaomi Home devices, choosing which devices to bridge, and adding the bridge to Apple Home. Reopen it any time from Settings.
- Pairing Diagnostics lets you mark an attempt, record the result shown in Home on your iPhone, and export a report with Bonjour discovery and HomeKit pairing progress.
- Refreshing an unused setup code is easier. If the bridge fails to start, you can retry from its settings.
- LAN reads keep successful values when some properties in a batch fail. A diagnostics export can also check whether offline devices respond.

Existing Apple Home pairings carry over when you update. Manually resetting pairing creates a new bridge identity, which you need to add to Home again.

Check for updates in Settings, or download the Developer ID signed and Apple notarized DMG or ZIP from GitHub Releases.
