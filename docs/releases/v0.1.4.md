# MijiaLAN 0.1.4

原生 macOS 版，Build 5。支持 macOS 15 及以上，安装包同时包含 Apple Silicon 和 Intel。

- 改善家庭 App 的设备控件：正确标记主要服务，将风速、挡位和童锁合并到原生控件，减少重复、无用的辅助开关，并改善浴霸的供暖与灯光映射。
- 优化能力和选项名称，区分同名服务、左右按键等控件，清理占位说明和重复名称。
- 防止设备返回超大数值、无效返回码或异常数值范围时导致崩溃，并修复网络监听启动时重复恢复 continuation 的并发风险。
- 修复菜单栏图标被隐藏或移出屏幕时打开 App 看不到面板的问题，并改进全局鼠标事件的线程处理。

部分辅助开关已移除或合并到原生控件；使用这些开关的家庭自动化可能需要重新选择控件。

安装包由 GitHub Actions 测试、构建、签名和公证，通过 macOS 15 双架构启动检查后发布。可用 `SHA256SUMS.txt` 核对下载文件。自动检查不代表所有设备型号、固件和家庭中枢均已完成实机验证。

Native macOS release, build 5. Requires macOS 15 or later; Universal for Apple Silicon and Intel.

- Improve Apple Home controls: mark the primary service, integrate fan speeds, gears and child locks into native controls, reduce redundant switches, and improve bath-heater heating and lighting mappings.
- Clarify capability and option names, distinguish duplicate service and button labels, and clean up placeholder descriptions.
- Prevent crashes from oversized device numbers, invalid result codes and malformed numeric ranges, and synchronize the network listener's one-shot startup continuation.
- Show the panel when the menu-bar icon has no visible position, and handle global mouse events on the main actor.

Some auxiliary switches have been removed or merged into native controls. Home automations using those switches may need their controls reselected.

GitHub Actions tests, builds, signs and notarizes the packages, then checks startup on both CPU architectures running macOS 15 before publication. Verify downloads with `SHA256SUMS.txt`. Automated checks do not replace physical-device and home-hub validation.
