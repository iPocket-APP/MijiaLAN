# MijiaLAN 0.1.7

## 简体中文

原生 macOS 版，Build 8。支持 macOS 15 及以上，同一安装包包含 Apple Silicon 和 Intel。

- 设置新增「诊断」区域，可一键导出 JSON 诊断报告，并在访达中定位文件。
- 报告包含设备在线状态、属性读数、重试状态和 HomeKit 读取失败项目，便于排查「家庭」中的感叹号或无响应问题。
- 支持创建附带诊断报告的邮件草稿；由你确认后发送。邮件 App 无法自动添加附件时，会显示报告文件供手动附加。
- 诊断报告包含设备名称、标识和读数，可先查看再分享；设备 token、网络地址和 HomeKit 配对密钥不作为导出字段。
- 源码构建改用仓库内维护的 MijiaCore，修复上游仓库不可用导致的构建失败。

安装包经 Developer ID 签名和 Apple 公证，并在发布前通过 macOS 15 双架构启动检查。0.1.6 用户可在设置中检查更新；也可从 GitHub Releases 下载安装包。已有设备配置和 HomeKit 配对继续使用原存储。

## English

Native macOS release, build 8. Requires macOS 15 or later; Universal for Apple Silicon and Intel.

- Add a Diagnostics section in Settings to export a JSON report and reveal it in Finder.
- Include device health, property readings, retry state and failed HomeKit reads to help investigate warnings or unresponsive accessories in Apple Home.
- Open an email draft with the report attached for you to review and send. If the mail app cannot attach it automatically, reveal the file for manual attachment.
- Reports contain device names, identifiers and readings and can be reviewed before sharing. Device tokens, network addresses and HomeKit pairing keys are excluded as export fields.
- Build from the locally maintained MijiaCore sources, restoring source builds after the upstream repository became unavailable.

Packages are Developer ID signed, Apple notarized and checked for startup on both CPU architectures running macOS 15 before publication. Version 0.1.6 users can check for updates in Settings, or download an installer from GitHub Releases. Existing device configuration and HomeKit pairing material continue to use their original storage.
