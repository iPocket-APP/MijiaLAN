# MijiaLAN 0.1.8

## 简体中文

原生 macOS 版，Build 9。支持 macOS 15 及以上，同一安装包包含 Apple Silicon 和 Intel。

- 修复只写式动作控件的 HomeKit 读数，将其作为瞬时开关处理，避免因设备不提供状态回读而显示无响应。
- 保留固件上报但设备规格未列出的模式值，在 App 中显示实际读数，减少模式开关误报无响应；控制写入仍按规格校验。
- 修复使用 1–255 等不同亮度刻度的灯具在「家庭」中的百分比换算，亮度设为 0 时关闭灯具。
- 改善未提供电机转速属性的空气净化器运行状态映射；提供转速的型号继续使用实际转速判断。
- 按标准设备规格提供智能床的姿态开关，过滤占位的 None 选项；厂商私有控制继续在 Mac 中使用。
- 按实际 HomeKit 服务映射判断设备是否支持桥接，在设备详情显示支持情况，并在诊断报告中增加对应字段。

安装包经 Developer ID 签名和 Apple 公证，并在发布前通过 macOS 15 双架构启动检查。可在设置中检查更新，或从 GitHub Releases 下载安装包。已有设备配置和 HomeKit 配对继续使用原存储。

## English

Native macOS release, build 9. Requires macOS 15 or later; Universal for Apple Silicon and Intel.

- Treat write-only action controls as momentary HomeKit switches, avoiding unavailable reads when a device does not report their state.
- Retain firmware-reported mode values missing from the specification and display the actual reading in the app, reducing unavailable mode switches. Writes remain validated against the specification.
- Scale lights with brightness ranges such as 1–255 to Home's percentage and switch them off when brightness is set to zero.
- Improve the current-state mapping for air purifiers without a motor-speed property while retaining actual-speed checks on models that provide one.
- Expose standard bed-position presets as switches, omit placeholder None options, and keep vendor-specific controls available on the Mac.
- Determine bridge support from the services that can actually be mapped to HomeKit, explain support in device details, and include it in diagnostic reports.

Packages are Developer ID signed, Apple notarized and checked for startup on both CPU architectures running macOS 15 before publication. Check for updates in Settings or download an installer from GitHub Releases. Existing device configuration and HomeKit pairing material continue to use their original storage.
