# MijiaLAN 0.2.2

## 简体中文

原生 macOS 版，Build 30。

- 最低系统版本降至 macOS 12（Monterey）。Apple 芯片和 Intel 共用同一安装包。
- 修复在 Apple「家庭」快速拖动亮度等滑杆时可能卡在“正在更新”的问题。桥接会先回复属性写入，设备处理完毕后再同步实际状态。

Monterey 上的启动、登录自启和回环 HomeKit 桥接在 Apple 芯片虚拟机中验证。

已安装的用户可在设置中检查更新。首次安装可下载经 Developer ID 签名和 Apple 公证的 DMG 或 ZIP。

## English

Native macOS release, build 30.

- The minimum system version is now macOS 12 Monterey. The Universal installer supports Apple silicon and Intel.
- Fixes an issue that could leave Apple Home stuck on “Updating” after a quick slider gesture. The bridge acknowledges property writes promptly and syncs the device's actual state once it settles.

Startup, launch at login, and loopback HomeKit bridging on Monterey were checked in an Apple silicon virtual machine.

Check for updates in Settings, or download the Developer ID-signed and Apple-notarized DMG or ZIP for a first installation.
