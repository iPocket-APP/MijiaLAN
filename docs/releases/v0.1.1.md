# MijiaLAN 0.1.1 · 原生 Swift / Native Swift

macOS 原生 Swift 版，版本 **0.1.1**，构建 **2**。需要 macOS 15 或更高版本，同一安装包包含 Apple Silicon 和 Intel 两种架构。

## 更新

- 修复异常读数、窗帘初始值和百分比精度；读数按声明的类型、范围与步长归一化，无法使用的值向「家庭」报告为不可用。
- 加湿器、除湿机和空调仅声明设备实际具备的能力；缺少原生服务的必需属性时保留电源、选项和传感器控制。
- 修复重复属性造成的重复 IID；每台配件最多 100 项服务，超过上限时在 Mac 设置里提示，其他功能仍可在 Mac 使用。
- 对齐 Rust 端的读写约束与 64 字节 UTF-8 限长；截断不会切断 Unicode 字符，原始设备名称保持不变。
- 增加早期 miIO 设备的属性转换表，以及加湿器、除湿机、取暖器、空调和窗帘的类别映射；具体能力仍取决于设备规格与固件。
- 菜单栏右键菜单增加设置入口，并修正桥接启动日志中的配件数量。

## 下载与升级

下载 `MijiaLAN-0.1.1-universal.dmg`，打开后将 App 拖入「应用程序」，或使用 ZIP。退出旧版后替换 App，再启动新版。设备配置和 HomeKit 配对继续使用原有钥匙串存储，不需要删除配置或重置桥。

App 和 DMG 使用 Developer ID 签名并通过 Apple 公证，均附加公证票据；App 启用 Hardened Runtime。`SHA256SUMS.txt` 用于核对下载文件。

## 验证范围

全量 Release 自动化测试 **142 项、34 个测试套件**通过，包含 73 组 Rust 参考值对照，以及真实回环 UDP miIO、加密 TCP HomeKit、异常读数恢复、UTF-8 边界和配对撤销后重新配对的组合测试。通用构建、签名、公证票据与 Gatekeeper 另行检查。

已在本机验证原生版运行及现有配对保留。Intel Mac 实机启动、所有设备型号和固件的逐项控制仍未全部验收。Apple 公证针对 macOS 软件发行，本项目没有 HomeKit / MFi 认证。桥接需要 Mac 与 App 持续运行。

Native Swift macOS release **0.1.1 (build 2)**, for macOS 15+, with a universal Apple Silicon / Intel app.

This update fixes invalid HomeKit readings, curtain initialization and percentages, unsupported climate modes, missing humidity thresholds, duplicate IIDs and service limits. It aligns read normalization and 64-byte UTF-8 limits with the Rust implementation, expands legacy miIO and category mappings, and adds Settings to the menu bar context menu.

The existing Keychain device configuration and HomeKit pairing are reused when replacing the app. Download the DMG or ZIP and verify it using `SHA256SUMS.txt`. The app and DMG are Developer ID signed, Apple notarized and stapled; the app uses Hardened Runtime.

All **142 Release tests in 34 suites** passed. Regression coverage includes 73 Rust reference vectors and a combined real loopback UDP miIO / encrypted TCP HAP / pairing rollback test. Automated tests and Apple notarization do not verify every device or firmware. Intel hardware has not been individually tested. This community project has no HomeKit / MFi certification.
