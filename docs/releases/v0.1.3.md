# MijiaLAN 0.1.3

原生 macOS 版，Build 4。支持 macOS 15 及以上，安装包同时包含 Apple Silicon 和 Intel。

- 修复 HomeKit 离线通知与恢复通知可能乱序的问题，避免旧错误覆盖已恢复的状态；包括离线期间新增订阅的情况。
- 改善多设备状态同步：已经读取完成的设备及时发布新状态，减少等待其他慢设备造成的延迟。
- 优化发行包体积，单独保留用于崩溃分析的符号文件。
- 引入 GitHub Actions 自动测试、Universal 打包、Developer ID 签名、公证及发布；安装包通过 macOS 15 双架构启动检查后才发布。

DMG 和 ZIP 中的 App 均已签名、公证并附带公证票据；可用 `SHA256SUMS.txt` 核对下载文件。

自动测试和启动检查不代表所有米家设备型号、固件及家庭中枢已经完成实机验证。状态同步反馈仍需结合具体设备与日志确认。

Native macOS release, build 4. Requires macOS 15 or later; Universal for Apple Silicon and Intel.

- Preserve HomeKit event order so a delayed offline error cannot replace a newer recovery, including initial subscriptions while unavailable.
- Publish completed device reads without waiting for unrelated slow devices.
- Reduce release executable size while retaining matching crash symbols separately.
- Automate testing, Universal packaging, Developer ID signing, notarization and release publication with GitHub Actions, gated by macOS 15 startup checks on both CPU architectures.

Both DMG and ZIP contain a signed, notarized and stapled app. Check downloads against `SHA256SUMS.txt`.
Automated checks do not replace physical-device and home-hub validation.
