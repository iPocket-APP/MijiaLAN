# MijiaLAN 0.1.9

## 简体中文

原生 macOS 版，Build 23。支持 macOS 15 及以上，同一安装包适用于 Apple 芯片和 Intel。

- 在设置顶部新增「登录时启动」，登录 Mac 后可自动在菜单栏启动 MijiaLAN。
- 改善 Apple「家庭」的灯具控制。关灯时可直接调高亮度，调到 0 时关灯。按设备确认后的状态更新，减少调光时的滑块回跳。
- 改善 HomeKit 的写入响应与断线恢复，减少控制后卡在「正在更新」的情况。
- 根据空气净化器的 PM2.5 读数显示 HomeKit 空气质量等级，并在 App 中统一显示 µg/m³。
- 本地诊断记录支持滚动保存，便于排查偶发的 HomeKit 与设备通信问题。

安装包经 Developer ID 签名和 Apple 公证，并通过 macOS 15 双架构启动检查。可在设置中检查更新，或从 GitHub Releases 下载安装包。

## English

Native macOS release, build 23. Requires macOS 15 or later. The Universal installer supports Apple silicon and Intel.

- Enable Launch at Login at the top of Settings to start MijiaLAN in the menu bar when you log in.
- Raise a light's brightness in Apple Home even when it is off, or set brightness to zero to turn it off. Home gets confirmed device readings, reducing slider jumps during dimming.
- Improve HomeKit write responses and connection recovery so controls spend less time showing Updating.
- Show a HomeKit air quality grade based on the air purifier's PM2.5 reading and display the unit consistently as µg/m³ in the app.
- Rotate local diagnostic captures to help investigate intermittent HomeKit and device communication issues.

Packages are Developer ID signed, Apple notarized, and checked for startup on both CPU architectures running macOS 15. Check for updates in Settings or download the installer from GitHub Releases.
