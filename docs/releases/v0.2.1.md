# MijiaLAN 0.2.1

## 简体中文

原生 macOS 版，Build 27。最低系统版本降至 macOS 13（Ventura），Apple 芯片和 Intel 共用同一安装包。

这个版本包含米家设备的局域网控制和 Apple「家庭」桥接。Ventura 上的亮度和色温滑杆支持用方向键调整。

已安装的用户可在设置中检查更新。首次安装可下载经 Developer ID 签名和 Apple 公证的 DMG 或 ZIP。

## English

Native macOS release, build 27. The minimum system version is now macOS 13 Ventura. The Universal installer supports Apple silicon and Intel.

This release includes LAN control for Mijia devices and bridging to Apple Home. The brightness and color temperature sliders support arrow-key adjustments on Ventura.

Check for updates in Settings, or download the Developer ID-signed and Apple-notarized DMG or ZIP for a first installation.
