## 报告语义

报告保留原生的 `recordedAt`、`app`、`language`、`bridge`、`accessories`、`paired`、
`keepsMacAwake`、`structureRevision`、`valuesRevision`、`devices`，并补充 Rust 标识、
平台、架构、OS 信息、构建号及 `pairingStateKnown`。
Mac 另保留原生 `macOS` 字段。
设备字段与原生对应，读数的 `value` 是紧凑 JSON 字符串。设备名称和读数仍是用户数据。

探测时间和退避状态只存在内存，重启后重新采集；`updatedAt` 为最近成功读取该设备
的时间，`valuesRevision` 为各设备 revision 的饱和累加，`structureRevision` 是桥实际
持久化的配置版本。桥停止时不读取钥匙串身份来推测配对状态，而报告
`pairingStateKnown: false`。CLI 不启动桥，也不跨进程查询 GUI 的桥状态。
